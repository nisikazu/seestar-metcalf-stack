# track-exclude-mean 調整設計メモ

## 目的と位置づけ

`track-exclude-mean` は、Metcalfスタックで星が通過する位置を予測し、
そのフレームの該当画素を平均から除外する観賞用の星軌跡低減方式である。
現行のmedianより星軌跡を強く抑えられる可能性がある一方、星と彗星のコア・尾が
重なった場合には対象信号も除外する。

したがって、測光用の既定処理とは分離し、まずは開発者向け・観賞用の明示的な
オプションとして調整する。定量測光の既定値にする前に、対象信号の保存量を検証する。

## 現在の実験実装

実装は `star_background_analysis.py` にある。現在の選択条件は次のとおり。

- 星固定スタックをRGB平均した画像から、8ピクセルぼかしを引いて高周波画像を作る
- 高周波値の上位0.3% (`99.7`パーセンタイル) を候補にする
- 画面端から半径+2ピクセル以内を除外する
- 既に採用した候補から18ピクセル以内を除外する
- 彗星中心から70ピクセル以内を除外する
- 最大48個の候補を採用する
- 各候補を半径8ピクセルの円形マスクとして、各フレームのMetcalfシフト位置へ移動する
- マスクされた画素を除き、残った有効サンプルだけでRGB各チャンネルを平均する

この処理では、星候補の選択には星固定medianスタックを使うが、候補画像の合成方法は
medianではなくマスク付きmeanである。

## 調整要素

### 1. 候補星の検出画像

候補を選ぶ前に、利用者が実際の判定画像を確認できる必要がある。

- 星固定スタックの種類: mean / median / rankfit
- RGBの統合方法: RGB平均 / 最大チャンネル / 個別チャンネル
- 背景推定の方法: 一様値 / 平面 / 二次曲面 / 大きなぼかし
- 高周波抽出のぼかし半径
- 表示用ストレッチ: percentile / sigma / MAD
- 正の高周波だけを候補にするか
- 候補位置の表示: 点 / 円 / 番号 / FWHM相当の輪郭

表示用ストレッチと候補判定の閾値は分離する。見やすくするためのPNGの階調変更が、
候補選択そのものを変えてはいけない。

### 2. 候補選択の閾値

固定の上位0.3%だけでなく、複数の方式を選べるようにする。

- 上位パーセンタイル: 例 `99.5`、`99.7`、`99.9`
- 標準偏差: 背景平均 + `N`σ
- ロバストσ: 背景中央値 + `N`×`1.4826×MAD`
- 絶対画像単位: 既知の背景レベルに対する閾値
- 局所S/N: 周囲のノイズに対する相対的な閾値

天体画像の高周波分布は正規分布とは限らないため、単純σだけに依存せず、
パーセンタイルまたはMADを比較できるようにする。

### 3. 候補の数と空間条件

- 最大候補数
- 最小候補間距離
- 画面端からの余白
- 候補の明るさによる上限・下限
- 飽和星を含めるか
- 星が密集した領域での優先順位
- 同じ星の重複検出をまとめる方法

候補数を増やすほど星軌跡は消えるが、誤検出と信号損失のリスクも増える。
GUIでは候補数を変更したとき、選択候補をすぐにオーバーレイへ反映する。

### 4. 星らしさの判定

高周波の明るさだけでは、星以外の構造も候補になる。将来的には次の条件を追加する。

- FWHMが想定PSF範囲に入ること
- roundnessが星の範囲に入ること
- 面積・連結成分の大きさ
- 彩度やRGB比が異常でないこと
- 飽和による大きな拡散像を除外または別扱いにすること
- コールドピクセル、ホットピクセル、宇宙線のような点状アーティファクトを除外すること

特に飽和星は中心だけでなく裾が広がるため、固定半径マスクでは取り残しやすい。
飽和フラグがある場合は、FWHMに応じた拡大マスクを検討する。

### 5. 彗星と対象信号の保護

現在は彗星中心から70ピクセル以内を候補から除外するだけで、尾の形状までは保護していない。
観賞用でも、彗星の尾が消えると結果の解釈を誤るため、次を検討する。

- 彗星コア保護半径
- コマの楕円または円形保護領域
- 太陽方向・反太陽方向を使った尾の保護扇形
- 尾の長さと幅
- 予報位置の不確かさを含む保護領域
- 利用者がPNG上で保護領域を追加・削除する操作
- 星マスクと保護領域が重なる場合の警告

候補星を除外する前に、彗星中心だけでなく尾の推定領域を保護する設計が重要である。

### 6. フレームごとの除外マスク

候補星の位置を各フレームへ移すときの調整要素は次のとおり。

- マスク半径
- 円形または楕円形マスク
- FWHMに応じた候補ごとの半径
- 星の明るさ・飽和状態に応じた半径
- サブピクセル位置を考慮したマスクの描画
- 登録誤差を見込む膨張量
- RGB共通マスクまたはチャンネル別マスク
- 画像外への移動時にラップさせないこと

現行実装は整数座標へ丸めた円形マスクをRGB共通で使う。星像の裾や登録誤差を含めるには、
FWHMと登録誤差から半径を自動計算する方が合理的である。

### 7. 合成と欠損画素

除外後の母数は全フレーム数ではなく、その画素で残った有効フレーム数にする。
そのうえで次を記録・制御する。

- 画素ごとの採用枚数マップ
- 除外された枚数マップ
- 最小採用枚数
- 採用枚数が少ない画素の警告
- 全サンプルが除外された画素の処理
- 平均、中央値、上位トリムの選択
- 除外後の局所背景を使うフォールバック

観賞用では全サンプル除外部分を補間する選択肢も考えられるが、測光用途では勝手に補間せず、
マスクまたは警告として残す方が安全である。

### 8. GUIでの確認項目

GUIは最終画像だけでなく、候補選択が妥当かを確認できることを重視する。

- 高周波成分画像
- 候補星番号付きオーバーレイ
- 彗星保護領域オーバーレイ
- 予測した星軌跡の表示
- mean / median / track-exclude-mean の左右またはスライダー比較
- 候補数、閾値、最小距離、マスク半径の操作
- 選択候補の個別ON/OFF
- 代表フレームを選んだマスク確認
- 採用枚数マップと除外枚数マップ
- 星軌跡残差、対照領域残差、背景ノイズ、彗星開口フラックスの表示
- 設定をJSON等へ保存し、同じ設定で本体を再実行できること

処理本体を毎回フル実行しなくても調整できるよう、低解像度プレビューや少数フレームの
試行結果を先に表示すると操作しやすい。

## 評価指標

候補設定は見た目だけで決めず、少なくとも次を記録する。

- 予測星軌跡マスク内の高周波正値残差
- 同面積の対照領域の高周波正値残差
- 軌跡/対照の残差比
- 星軌跡のp95残差
- 除去できた星の面積と残留面積
- 背景ノイズの標準偏差またはMAD
- 画素ごとの採用枚数分布
- 彗星コア・尾の開口フラックス変化
- 既知の基準星のフラックス変化
- 処理時間とメモリ使用量

特に、星軌跡残差だけを最小化すると、彗星や尾まで消す設定が最良に見える可能性がある。
対象信号の保存量と同時に評価する。

## 初期の推奨方針

1. 現行medianを安全な基準として残す。
2. `track-exclude-mean` は観賞用の明示オプションに限定する。
3. 最初のGUIでは高周波画像、候補オーバーレイ、候補数、閾値、マスク半径、彗星保護半径を扱う。
4. 候補を増やす前に、FWHM・roundness・飽和状態で誤検出を減らす。
5. 彗星コアと尾の保護領域を導入してから、候補数の既定値を検討する。
6. 各設定で候補FITS、PNG、候補マスク、採用枚数マップ、評価CSVを保存する。

## 注意

この方式は、星軌跡の低減には強いが、物理的に存在する信号を「星らしい」と判断して
消す可能性がある。観賞用の見栄えと科学的な保存性は目的が異なるため、同じ処理名・
同じ既定値で兼用しない。
