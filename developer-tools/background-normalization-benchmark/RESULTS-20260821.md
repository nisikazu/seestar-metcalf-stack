# Background Normalization Timing Results: 2026-08-21

These measurements document the first implementation of `offset`, `plane`,
and `quadratic` background normalization that subtracts each accepted frame's
fitted background to zero during arithmetic. A constant RGB output offset is
added only after stacking as a signed-range safeguard. It is the arithmetic
mean of the accepted frames' fitted local DC levels; it is not a restored
background model.

## Interpretation and repeatability

Windows filesystem cache, Siril startup, and intermediate-file reuse change
the total runtime substantially: the two full-session `none` runs differed by
about 249 seconds. Do not compare the initial cold `none` timing directly to
subsequent modes. For a more defensible performance comparison, execute each
mode at least three times and rotate the mode order between runs.
